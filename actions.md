# Текущая задача

## Цель
Добавить на страницу списка оборудования возможность массового удаления выбранных единиц оборудования.

## 1. Массовый выбор оборудования

На странице «Оборудование» нужно добавить выбор оборудования через checkbox.

Требования:
- у каждой строки оборудования должен быть checkbox;
- в шапке таблицы должен быть checkbox «выбрать все» для текущей страницы;
- выбранное оборудование должно отправляться на сервер списком id;
- массовое удаление должно работать с текущей пагинацией;
- выбор «выбрать все» выбирает только оборудование на текущей странице, не все оборудование во всей базе.

## 2. Кнопка массового удаления

Добавить кнопку:
- «Удалить выбранное».

Требования:
- кнопка должна быть рядом с таблицей оборудования;
- если ничего не выбрано, кнопка должна быть disabled или при отправке должно появляться сообщение;
- перед удалением нужно показать подтверждение:
  - Bootstrap modal;
  - или отдельная страница подтверждения;
- удаление должно выполняться только через POST;
- нельзя удалять через GET.

## 3. Серверная логика удаления

Нужно добавить view для массового удаления оборудования.

Требования:
- принимать список equipment_ids из POST;
- удалять только оборудование текущей организации;
- проверять права пользователя на удаление оборудования;
- если у пользователя нет прав, вернуть 403;
- нельзя удалить оборудование другой организации даже при подмене id;
- после удаления сделать redirect обратно на список оборудования;
- сохранить текущие фильтры/поиск/per_page/page по возможности;
- показать сообщение об успешном удалении, например:
  «Удалено оборудования: 5».

## 4. Права доступа

Массовое удаление должно быть доступно только тем ролям, у которых есть право удалять оборудование.

Согласно текущей матрице:
- ADMIN может удалять оборудование;
- DISPATCHER не может удалять оборудование;
- ENGINEER не может удалять оборудование;
- CHIEF_ENGINEER не может удалять оборудование.

Требования:
- кнопку «Удалить выбранное» показывать только пользователям с правом equipment.delete;
- checkboxes можно скрывать для пользователей без права удаления;
- серверная проверка обязательна.

## 5. Интерфейс

Требования:
- использовать Bootstrap;
- добавить аккуратное подтверждение удаления;
- не ломать существующую таблицу оборудования;
- не возвращать колонку «Инвентарный номер», если она была убрана ранее;
- сохранить пагинацию и выбор количества записей на странице.

## Ограничения

- Не менять models.py.
- Не создавать миграции.
- Не трогать 3D-визуализацию.
- Не ломать поиск, фильтры и пагинацию оборудования.
- Не менять права доступа без необходимости.
- Не удалять оборудование через GET.
- Не удалять данные другой организации.
- Не показывать массовое удаление пользователям без права удаления.

## Ожидаемый результат

После выполнения Codex должен показать:
- список измененных файлов;
- какой view добавлен для массового удаления;
- какой URL добавлен;
- какие templates обновлены;
- как реализован checkbox выбора;
- как реализовано подтверждение удаления;
- как проверяются права;
- как защищено удаление от подмены id другой организации;
- как сохраняются фильтры и пагинация после удаления;
- команды для проверки проекта.
